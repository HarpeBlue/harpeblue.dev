# harpeblue.dev

Professional portfolio for Harold Peñaloza / HarpeBlue.

## Goal

Build a fast, memorable, recruiter-friendly portfolio that demonstrates frontend judgment, React experience, visual identity, and engineering growth.

Primary target:

```txt
Frontend Software Engineer
```

## Stack

- Astro
- TypeScript
- CSS
- HarpeBlue Signal

## Commands

| Command | Action |
| --- | --- |
| `npm run dev` | Start local dev server |
| `npm run build` | Build production site |
| `npm run preview` | Preview production build locally |
| `npm run astro` | Run Astro CLI commands |

## Commit Rule

Use gitmoji commits after completed steps or features.

No commit should be created without Harold's approval.
